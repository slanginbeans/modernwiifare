# ADR 0004: Apache-2.0

Status: **accepted** (2026-11-13)

- The project is licensed Apache-2.0, matching IW4L, our base.
- No code is taken from mw2-recompiled (GPL-3.0). It is a behavioural reference only.
- If we ever need GPL-3.0 code, Apache-2.0 code can be combined into a GPL-3.0 work, so that path stays open. Taking it would require an ADR.
